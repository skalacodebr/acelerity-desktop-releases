# Acelerity Desktop

App de barra de menus para macOS que liga o botão Bluetooth (BLE-M3) ao Aceleres: Jarvis por voz, atendimento assistido com sugestões, lembretes e atas de reunião.

**Download:** baixe o `.dmg` da [versão mais recente](https://github.com/skalacodebr/acelerity-desktop-releases/releases/latest), arraste o app para Aplicativos e abra. O app é assinado e notarizado pela Apple e se atualiza sozinho.

Requisitos: macOS 14 ou superior, Mac com Apple Silicon, login no Aceleres e o controle BLE-M3.

Este repositório contém apenas os instaladores e o feed de atualizações.
